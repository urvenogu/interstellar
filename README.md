# Interstellar
Ava index.html brauseris. Paigaldamist ega ehitamist pole vaja.

1. Vali planeet. Ülejäänud planeedid muutuvad mustvalgeks ning vaade liigub pakkimise juurde.
2. Vali tühja seljakotti täpselt viis eset. Valiku muutmiseks eemalda esmalt mõni ese.
3. Vajuta „Vaata reisi tulemust”. Iga kaasavõetud eseme mõju ja reisi kokkuvõte sõltuvad valitud planeedist ning varustusest.
4. „Alusta uut reisi” tühjendab valikud. Planeeti või varustust muutes peidetakse eelmine tulemus.

Tulemus on mänguline kosmoseseiklus. Sihtkohtade kirjeldused, varustuse mõjud ja põhiesemed on muudetavad app.js failis destinations-objektis.

HTML/CSS/JavaScript teostus Figma Main page kujundusest. Pildid on kohalikud; kirjatüübid laaditakse Google Fontsist. Telefonis on esemed ühes veerus.
