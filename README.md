# Interstellar - reis galaktikas
1) Public link: https://interstellar-three-bice.vercel.app/
2) Kujundus: https://www.figma.com/design/QM3jf6dMoDaiOzcsoCn2tX/Interstellar?node-id=73-248&t=Nvz4xc5uCRfepmTG-0
3) Githubi repo: https://github.com/urvenogu/interstellar/

Millega on tegemist?
Tegemist on õppimise eesmärgil loodudu kodulehega. 
Vali planeet, paki 5 asja etteantud esemete hulgast ja alusta reisi. 

Tiim
Elijah, Valmar, Diana, Siimon, Priidik, Urve.

Tiimi missioon
Oli luua mänguline reisi planeerija, kus kasutaja valib sihtkoha ja varustuse ning saab oma valikutest sõltuva tulemuse või loo.

Põhitegevuse näide: vali planeet → vali kuni viis eset → alusta seiklust → saa oma varustusest ja saare tingimustest sõltuv tulemus.

Kuidas alustasime
Valisime tiimiga ühiselt, et loome reisiplaneerija. Reisi sihtkohaks valisime galaktika ja erinevad planeedid.
Esimese visuaali, mille põhjalt arendasime välja lehe idee ja funktsionaalsuse, lõime lovables. https://planet-pack-and-pioneer.lovable.app/
